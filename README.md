# Мой дом. Владивосток

Интерактивная карта Владивостока: за три нажатия от района до своего дома и «паспорт дома» — кто отвечает, что сломано, что будут ремонтировать. Можно сообщить о проблеме, разобрать квитанцию и вести личный кабинет.

## Проблема
Жители не знают, кто отвечает за дом и двор, куда жаловаться, почему выросла квитанция и что меняется рядом. Информация разбросана по разным сайтам и написана канцеляритом.

## Решение
Навигация как зум: **Город → Район → ЖК → Дом → Действие**. Состояние живёт в адресе страницы — ссылкой на дом можно поделиться.

- Паспорт дома: этажность из OpenStreetMap, управляющая компания, капремонт, открытые жалобы, «здоровье дома», работы рядом.
- Клик по любому дому на приближенной карте открывает его паспорт.
- «Сообщить о проблеме»: фото → тип и описание → адрес → сервис по ключевым словам определяет категорию и ответственного и составляет текст обращения. У каждого обращения своя страница с фото и описанием.
- «Разобрать квитанцию»: отдельно коммуналка, капремонт, электроэнергия; PDF или текст → строки простыми словами, график по месяцам, что выросло и что делать.
- «Что меняется в городе»: ремонты и отключения, поиск по улице, пересказ любого объявления.
- Личный кабинет: мои дома, обращения, квитанции, счётчики, соседи, настройки.

## Запуск
Нужен Node.js 20+ и ключ 2GIS MapGL.

```bash
cp .env.example .env
```
Впишите ключ в `NEXT_PUBLIC_2GIS_KEY` в `.env`, затем:
```bash
npm install
npx prisma db push
npm run seed
npm run preview
```
Откройте http://localhost:3000. Для разработки — `npm run dev`.

`lib/ai` — слой «умных» функций: категория и служба для жалобы, текст обращения, разбор квитанции, пересказ работ, сводка по району. Сейчас он работает на правилах и справочниках (`lib/ai/rules.ts`), без внешних моделей и ключей; вход и выход описаны схемами zod (`lib/ai/schemas.ts`), так что модель можно подключить за тем же интерфейсом. Фото квитанций не распознаются — только PDF с текстом или вставленный текст.

## Демо-сценарий
1. Заставка → карта с 5 районами → наведите на район → клик по **Ленинскому**.
2. Паспорт района → **ЖК «Фрегат-2»** → дом.
3. В паспорте: этажность, ссылки на ГИС ЖКХ и Фонд капремонта, 3 открытые жалобы, здоровье дома.
4. «Сообщить о проблеме» → «Пример фото» → «Дорога», администрация города, текст обращения → «Сохранить на карте» → страница обращения.
5. «Разобрать квитанцию» → «Пример квитанции» → строки, график, рост после 1 октября 2026.
6. «Работы» → поиск «Посьетск» → авария на теплотрассе; клик по жёлтому маркеру открывает работу.
7. Клик по коралловой точке → страница обращения: фото, описание, «Меня тоже касается».
8. Назад к городу → «Слои» → «Проблемы» → скопление подтоплений на Второй Речке.
9. Кабинет → регистрация → сохранённый дом → кнопка «Мои дома» над «Кабинетом».

## Архитектура
Next.js 15 (App Router) + React 19 + TypeScript, Tailwind CSS v4 и shadcn/ui, Prisma + SQLite, zod, карта 2GIS MapGL.

- `app/(map)/` — все страницы с общим layout: карта монтируется один раз, страницы рендерятся в панель поверх неё.
- `app/api/` — поиск, дом по точке, жалобы, правила (`/api/ai/*`), вход и кабинет.
- `lib/queries.ts` — запросы к БД; `lib/search.ts` — адреса и поиск; `lib/ai/` — правила разбора (классификация, квитанции, пересказы, сводки) и чтение PDF; `lib/auth.ts`, `lib/cabinet.ts` — вход и данные кабинета.
- `components/map/` — карта и её слои; `components/panel/`, `components/house/`, `components/flows/`, `components/cabinet/` — экраны.
- Самопроверки: `npx tsx lib/<имя>.test.ts`.

Подробная спецификация — `START_PROMPT.md`, карта файлов — `filemap.md`.

## Источники данных
- Районы, население, микрорайоны, ЖК — `data/vladivostok_seed.json` (открытые источники).
- Дома и адреса — © участники OpenStreetMap, ODbL (`data/osm-*.json`).
- Границы районов — 2GIS (`public/geo/districts.geojson`).
- Тарифы в примере квитанции — реальные тарифы Владивостока до и после индексации 1.10.2026.
- Городские работы — пересказы публикаций осени 2026, источник и дата указаны в каждом тексте.
- Управляющие компании, жалобы и квитанции — демо-данные, помечены `isDemo`.

## Что нужно для реального запуска
- Данные домов и УК из ГИС ЖКХ / «Реформы ЖКХ».
- Отправка обращений через платформу обратной связи «Решаем вместе».
- Автоматический сбор публикаций администрации о работах и отключениях.
- Модерация жалоб и объявлений.
- Настоящий вход через Госуслуги (сейчас — демо).
