# SPEC — «Мой дом. Владивосток» (myVDKmap)

**Нормативный источник — [`START_PROMPT.md`](../START_PROMPT.md).** Этот файл фиксирует решения и уточнения поверх него; ссылки вида «§5.2» — на разделы START_PROMPT.md. При расхождении побеждает START_PROMPT.md, кроме пунктов раздела «Уточнения» ниже.

## Цель
Интерактивная карта Владивостока: Город → Район → ЖК → Дом (паспорт) → Действие (жалоба, квитанция, работы, кабинет). Состояние в URL, ссылкой на дом можно поделиться (§1–2).

## Не цели
Реальные интеграции с городскими системами, настоящая отправка обращений, платежи, микросервисы, Docker, деплой, геймификация, карусели поверх карты, брендинг Госуслуг (§12). Ничего сверх описанного.

## Стек
Next.js 15.5 (App Router, webpack в dev) · React 19 · TypeScript strict · Tailwind CSS v4 + tw-animate-css · shadcn/ui на `radix-ui` · lucide-react · framer-motion · sonner · next-themes · recharts · Prisma 6 + SQLite · zod 4 · @turf/turf · 2GIS MapGL (`@2gis/mapgl`, единственная карта) · tsx (сид и самопроверки) · Node 20+.

## Архитектура
Модули и их ответственность — §4. Маршруты и API — §2. Все страницы в `app/(map)/` с общим layout: карта монтируется один раз.
Зависимость `lib/queries.ts → lib/search.ts` односторонняя.

## Данные
- Подготовленные файлы — §3.1; лежат в проекте по путям из `inputs/` (`data/`, `public/geo/`, `public/demo/`, `lib/fixtures/`, `scripts/`) **байт в байт**.
- Схема Prisma — §3.2; справочники `lib/types.ts` — §3.2; сид — §3.3.

## Экраны и дизайн
Раскладка, карта, панели, паспорт, мастера, кабинет, поиск, заставка — §5. Дизайн решён — §7 (токены, shadcn-настройки, анимации). Отдельный визуальный проход не делается; оркестратор сверяет результат со §5 и §7.

## Логика
§6.1 — без ИИ: только правила и справочники (`lib/ai/rules.ts`), внешних моделей нет; поиск — §6.2; ленивый паспорт OSM-дома — §6.3; улицы работ — §6.4; здоровье дома — §6.5.

## Окружение
`.env.example`, скрипты `package.json`, `.claude/launch.json`, README — §8. Ключ 2GIS только в `.env` (уже существует, не трогать и не коммитить).

## Уточнения (решения оркестратора)
1. `lib/fixtures/bills.ts` содержит **4** квитанции (`DEMO_BILLS`, 2026-08…2026-11), а не 3 — сид берёт все из фикстуры как есть.
2. Самопроверки — `lib/**/*.test.ts` на `node:assert`, запуск `npx tsx <файл>`; отдельного тест-раннера и скрипта-агрегатора нет.
3. `npm run setup` может перезаписать `public/geo/*` (fetch-geo.mjs). В задачах разработки запускать не `setup`, а `npx prisma db push && npm run seed`; изменения `public/geo/*` в git — только осознанно.
4. Папка `inputs/` удаляется после переноса (файлы переезжают, сверка по контрольным суммам).
